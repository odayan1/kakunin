📜 英検2級リスニング 虎の巻

Q-UP英語塾｜エリー先生　｜　アプリの「👩‍🏫 エリー先生と解き方レッスン」で、1つずつ体験できます

0. まず知っておくこと

  • 第1部＝会話15問、第2部＝説明文・放送15問。英文は1回しか読まれない。答える時間は1問10秒。
  • 差がつくのは「聞く前に何が問われるかを決めること」と「聞いた後にどこで答えが決まったかを分かること」。

1. 聞く前：先読み（選択肢を先に読む）

答えを塗ったら、すぐ次の問題の選択肢を読む。選択肢の形で、何が問われるかが決まる。

選択肢の形問われること聞くところレッスン
動詞で始まる
Buy… / Go… / Ask…		何をするか（動作）「〜する」の言葉。最後に決まった行動1・4
名詞が並ぶ（物・人の名前・場所）
A notebook. / At the café.		それが何か物・人・場所の名前が出たところ2
文（主語＋動詞）が並ぶ
She needs… / The hotel is…		何が起きたか・困りごと・理由だれに何が起きたか（話の流れ）3
数・時刻が並ぶ
At 10:30. / At 10:45.		いつ・いくつ（たいてい変更後）数字が2つ出たら「いつもは」と「今日は」を分ける5

4つに共通する言葉 → 話題の予想になる。迷っても10秒以内に塗って、次の先読みへ。1問を引きずらない。

2. 聞いた後：結局どうする？　結局どうなる？

答えは、話の最後のほうで決まることが多い。質問に合わせて、次のどれかを自分に聞く。

質問自分に聞くこと答えが決まるところ
What will ～ do (next / tomorrow)?結局どうする？最後の I'll ～ / Let's ～ / I've decided to ～
What did ～ finally do?結局どうした？In the end / Finally のあと
What is the man's / woman's problem?結局どうなっている？（困りごと）but / Actually のあとの本当の困りごと
What is one thing we learn about ～?結局どうなる？（分かったこと）言い換えで出る事実
Why ～?結局なぜ？because / so、転換語のあとの本当の理由

3. 転換語と追加語（対の用語）

転換語と追加語は対になる言葉。違いは、話の流れが変わるか、続くか。

転換語（流れが変わる）追加語（流れが続く）
例however, but, actually, instead, unfortunately, at first（→あとで変わる合図）, in the endalso, and, besides, in addition, too
聞き方転換語のあとに、本当に言いたいこと・答えが来やすい。前の話は消えることが多い前と同じ向きの話がもう1つ足される。「変更がもう1つ」「よい点がもう1つ」

アプリの「スクリプトで学習」では、転換語に緑、追加語に青の下線を引いてある。

4. 正解は「言い換え」で出る

  • 正解の選択肢は、英文と同じ言葉ではなく言い換え。言葉ではなく意味で選ぶ。
  • 語の言い換え：notebook → something to write in／uncle → a relative
  • まとめ：bus → public transportation／apples and bananas → some fruit
  • 言い方の言い換え：come to my house → go to the woman's house／fifteen minutes later than 10:30 → at 10:45

5. ひっかけ

  • 不正解は英文に出てきた語で作られる。「聞こえた語＝正解」ではない。
  • 会話の途中で出て断られた案（Should I ～? → I'd rather ～）、At first の計画、「いつもは」の数字は、ひっかけになりやすい。
  • 転換語の前にある話は、ひっかけの材料になることが多い。

6. 第1部（会話）と第2部（説明文・放送）

第1部：最初の一言で「だれとだれが・どこで」

Honey → 夫婦、Dad / Mom → 親子、Hello, ○○.（最初に電話の音）→ お店・会社への電話。

第2部：3つのタイプ

タイプ聞くところ
人の話（人名＋過去形）At first → However → In the end。結局どうした？
放送（Attention, … / Good evening, listeners.）変更・例外。数字が2つ出たら、変わったあとの数字
豆知識・科学Many people believe（よくある思いこみ）→ However / Actually（本当は）。むずかしい語は直後に説明される

7. 音のつながり 5ルール

ルール何が起きる例
つながる子音＋母音がくっつくpick up → ピカップ
ラ行になる母音にはさまれた t がラ行にget up → ゲラップ
消えるt・d がほとんど聞こえないlast night → ラスナイ
混ざるt / d ＋ you → チュ・ヂュDid you → ディヂュ
弱くなるto・the・him など軽い語が弱くwant to → ワナ

8. このアプリの進め方

  1. 本番モードで今の力をチェック（全部聞き取れなくても大丈夫・途中でやめてもよい）
  2. エリー先生と解き方レッスンで、この虎の巻の1〜5を1問ずつ体験
  3. 1問ずつ練習：解いたら「スクリプトで学習」で1文ずつ聞き直し → 「シャドーイングで練習」で声に出す
  4. 力試し5問で、解き方が身に付いたかを確かめる
