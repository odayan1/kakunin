Q-UP英語塾｜エリー先生
仮の版です（中身はこれから仕上げます）

0. まず知っておくこと

  • 第1部＝会話15問、第2部＝説明文15問。英文は1回しか読まれない。答える時間は1問10秒。
  • だから差がつくのは「聞く前の準備」と「どこを聞くか」。

1. 聞く前：選択肢を先に読む

  • 答えを塗ったら、すぐ次の問題の選択肢を読む。
  • 選択肢が動詞で始まる → 「何をするか（次の行動）」が問われる。人の名前・場所が並ぶ → それが問われる。
  • 4つに共通する言葉 → 話題の予想になる。
  • 迷っても10秒以内に塗って、次の先読みへ。1問を引きずらない。

2. 第1部（会話）

最初の一言で「だれとだれが・どこで」

Honey → 夫婦、Dad / Mom → 親子、Hello, ○○. → お店・会社への電話。

質問の型（よく出る順）

質問どこを聞く？
What is one thing we learn about ～?話の中身と合うもの（言い換えに注意）
What is the man's / woman's problem?その人が言った困りごと
What will ～ do (next / tomorrow)?最後の I'll ～ / Let's ～
Why ～?because / so の前後
What does ～ want … to do?Can you ～ / Could you ～ の頼みごと

ひっかけの定番

  • 不正解は会話に出てきた単語で作られる。「聞こえた単語＝正解」ではない。
  • 途中で出た案はあとで覆る（Should I ～? → 「いや、～にしよう」）。最初の案は不正解に回される。
  • But / Actually / Instead のあとに答えの根拠。

3. 第2部（説明文）

タイプ聞くところ
人物の話
（人名＋過去形）		最終的に何をしたか。At first の案・ほかの人の提案は消す。However / In the end / Finally のあとが核心。
アナウンス
（Attention, … / Welcome to …）		変更・例外・条件。数字が2つ出たら（前は～→今は～）ほぼ問われる。
豆知識・科学テーマ→問題→特徴・解決→補足。むずかしい語は直後に説明されるので、その説明を聞く。

時間の言葉が2つ以上（used to / now / soon / last year）出たら、「質問はどの時点？」を確かめる。

4. 音のつながり 5ルール

ルール何が起きる例
つながる子音＋母音がくっつくpick up → ピカップ
ラ行になる母音にはさまれた t がラ行にget up → ゲラップ
消えるt・d がほとんど聞こえないlast night → ラスナイ
混ざるt / d ＋ you → チュ・ヂュDid you → ディヂュ
弱くなるto・the・him など軽い語が弱くwant to → ワナ

5. 正解は「言い換え」で出る

  • 正解の選択肢は、英文と同じ言葉ではなく言い換え。言葉ではなく意味で選ぶ。
  • 語の言い換え：buy → purchase／まとめ：apples and bananas → some fruit／言い方の言い換え：I'll call the shop tomorrow → Contact the store.

6. このアプリでの練習の3段階

  1. ふつうに解く（1回だけ聞いて、10秒で答える）
  2. 解説で「流れた順のスクリプト」を見ながら聞き直し、聞き取れなかった所を見つける
  3. 「シャドーイングで練習」で1文ずつまねして声に出す → 英文をかくしても言えるまで
